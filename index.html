2. O que são tags semânticas?

R:Tags semânticas são elementos de código que indicam claramente o seu significado e a função do conteúdo que carregam, tanto para o navegador quanto para quem desenvolve.


3. O HTML é uma linguagem de programação?

R:O HTML não é uma linguagem de programação, mas sim uma linguagem de marcação de hipertexto.
